# BCN Portfolio Challenge

Portfolio cá nhân theo concept poster BCN Portfolio Challenge:
- Dark / black UI
- Neon purple accent
- Creative developer aesthetic
- Responsive
- Project cards
- Skills
- Contact CTA
- CSS avatar placeholder
- Không cần ảnh ngoài để chạy bản demo

## Chạy local

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Cá nhân hóa

Mở `components/Portfolio.tsx` và thay:
- YOUR NAME
- phần About
- projects
- skills
- email
- GitHub / LinkedIn / Instagram

## Deploy Vercel

Push project lên GitHub, sau đó import repository vào Vercel.
Build command: `next build`
Install command: `npm install`
